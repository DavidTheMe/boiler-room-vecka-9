# Boilerroom vecka 11-13

Detta är en hemsida där man kan söka upp och lägga till låtar i en spellista (dock så blev denna feature inte helt klar)


# Features

 - Söka efter låtar

 - Dark mode

 - Se nya och populära låtar

 - Statistik om de populäraste låtarna


# Hur man använder

Tryck på "Lägg till i din spellista" för att lägga till låten i din spellista
Om du vill söka efter en specifik låt så kan du skriva in artisten eller låtens namn i sökfältet och sedan trycka "Sök"
När du vill gå hem till första sidan igen kan du trycka på "Hem"
I högra hörnet finns det en knapp för att sätta på och stänga av darkmode
